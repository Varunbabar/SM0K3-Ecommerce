# SM0K3 – Sneaker E-Commerce

A full-stack sneaker e-commerce website built using React.js, Spring Boot, and MySQL.

## Technologies
- React.js
- Java & Spring Boot
- MySQL
- Tailwind CSS

```bash
npm start
```

Backend: Run `BackendApplication.java` from your Java IDE.
